# Olympia_Oyster_Restoration_Genetics_2026
Repository holding raw data and code for olympia oyster restoration genetics paper

**Data files** \
SNPs_Final.gen and Mhap_FINAL_Filtered.gen are the genepop files used in the paper for analysis of population structure, Fst, etc. These base files can be converted to .str (structure files) via PGDSpider for Structure analyses. \
VCF files that precede the genepop files are also available (OlyO_....)

Sample names in the .VCF file are shortened in some cases, but the numbers are consistent across file types. "WB" is Willapa bay, "MB" is Mystery Bay, "LS" is Little Skookum Inlet, "BL" is Burley Lagoon, "PGB" is Port Gamble Bay, "Disco" is Discovery Bay, "FB" is Fidalgo Bay, "CS" is Central Sound or Mud Bay. See metadata summary file for GPS coordinates and other site info.
